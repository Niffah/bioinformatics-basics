# Bioinformatics Basics: DNA Analytics with Python

This repository contains foundational Python scripts designed to process and analyze biological sequences. 

## Scripts Included
* **gc_content_calculator.py**: A clean script that calculates the GC-content percentage of genomic data strings, a key baseline metric used in tracking DNA stability and structural changes in longevity research.

## Skillsets Highlighted
* String manipulation and parsing in Python
* Functional programming structures
* Application of coding logic to molecular biology problems
