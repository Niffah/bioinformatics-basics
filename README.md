# Bioinformatics Basics: DNA Analytics & Translation with Python

This repository contains foundational Python scripts designed to process, translate, and model biological sequences, demonstrating structural data management workflows.

## Scripts Included
1. **gc_content_calculator.py**: A clean automation script that calculates the GC-content percentage of genomic data strings, a key baseline metric used in tracking DNA stability and structural changes in longevity research.
2. **dna_translation_mutator.py**: An advanced script utilizing nested hash tables (dictionaries) to translate messenger RNA (mRNA) sequences into amino acid protein chains. It includes a mutation simulator to analyze how single nucleotide alterations disrupt biological protein expression profiles over time.
3. **count_adenine.py**: A foundational script demonstrating basic string manipulation and character parsing logic to isolate and count targeted Adenine bases within genomic strings.

## Skillsets Highlighted
* Complex string parsing and indexing in Python
* Key-value map architectures (Dictionaries) for biological translation modeling
* Functional programming, error checking, and code reusability
* Application of computational logic to molecular genetics problems
